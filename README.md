# Hammerhead Karoo extension for controlling sports cams

## Supported devices

For now only GoPro cameras are supported.

### GoPro

| Camera | Minimum firmware version |
| ------ | ------------------------ |
| MAX 2 | v01.10.00 |
| HERO13 Black | v01.10.00 |
| HERO12 Black | v01.10.00 |
| HERO11 Black Mini | v01.10.00 |
| HERO11 Black | v01.10.00 |
| HERO10 Black | v01.10.00 |
| HERO9 Black | v01.70.00 |

Up-to date supported cameras list can be found [here](https://gopro.github.io/OpenGoPro/#compatibility).
